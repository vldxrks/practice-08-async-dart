# Документація станів

Умовою роботи передбачені **реальні скриншоти запущеного застосунку**.
Це середовище не має Flutter SDK / емулятора, тому справжні знімки не були створені. Не підміняйте їх макетами.

Після `flutter run -d chrome` збережіть до `docs/`:

1. `01-loading.png` — натисніть кнопку оновлення і швидко зробіть знімок, поки триває спільне завантаження.
2. `02-error.png` — встановіть 100 % збоїв API і дочекайтеся помилки з кнопкою «Повторити».
3. `03-empty.png` — встановіть 0 % і активуйте «Порожні дані (демо)».
4. `04-data.png` — вимкніть режим порожніх даних; дочекайтеся показань усіх датчиків.
5. `05-live-alert.png` — зачекайте, поки значення вийде за межі, та зафіксуйте підсвічену картку і SnackBar.
6. `06-paused.png` — натисніть «Пауза» і зафіксуйте незмінні показання.
7. `07-single-sensor-error.png` — встановіть 50 % збоїв, щоб показати окрему помилку датчика.

Необов'язково: `flutter screenshot -d <device-id> -o docs/04-data.png`.
